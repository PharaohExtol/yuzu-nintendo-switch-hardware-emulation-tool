## 🔧 Instalación

### Paso 1: Descargar y Extraer

- Descarga `Yuzu-Switch-Hardware.zip` (~50 MB)
- Extrae con WinRAR o 7-Zip. **Sin contraseña.**

### Paso 2: Añadir las Keys

- Abre la carpeta `/keys`
- Copia `prod.keys` dentro
- No renombres el archivo

### Paso 3: Instalar Firmware

- Abre Yuzu
- Ve a **File → Install Firmware**
- Selecciona el archivo ZIP del firmware
- Espera a que se complete la instalación

### Paso 4: Configurar Gráficos

- Abre **Emulation → Configure → Graphics**
- Selecciona **Vulkan**
- Ajusta resolución y límite de FPS

### Paso 5: Añadir Juego y Control

- **File → Load File** → elige NSP o XCI
- Conecta el mando
- Asigna botones en **Emulation → Configure → Controls**
